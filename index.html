kubectl logs -f <pod> -c <c>Stream container logs
kubectl exec -it <pod> -- shShell into container

Practice Questions

CKA / CKS Quiz

Scenario-based questions with detailed explanations. Covers real exam patterns.

✦ QUESTION 1 OF 50 · NETWORKING
A Pod in namespace payments cannot reach a Pod in namespace orders. Both pods are running. A NetworkPolicy exists in orders namespace. What is the most likely cause?
A The pods are on different nodes
B The CNI plugin is not installed
C The NetworkPolicy in orders namespace does not allow ingress from the payments namespace
D Cross-namespace communication is disabled by default in Kubernetes
✅ Correct. NetworkPolicy is namespace-scoped and deny-by-default once applied. If a NetworkPolicy exists in the orders namespace, it will block all ingress not explicitly allowed. The fix is to add an ingress rule allowing traffic from the payments namespace using namespaceSelector with appropriate labels. Cross-namespace communication is allowed by default in K8s without NetworkPolicy.
